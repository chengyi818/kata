# blogwatcher

## 问题背景

关注的技术博客和 RSS 订阅源更新频繁，手动逐个检查效率低，容易错过重要更新。该技能将订阅管理集成到终端，自动追踪和汇总新内容。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/blogwatcher
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

### 添加订阅源

支持 RSS 和 Atom 格式，添加博客或新闻源地址，自动识别订阅类型并配置更新频率。

### 检查更新

批量检查所有已订阅源，标记有新文章的源，返回更新数量和最后发布时间。

### 获取新文章摘要

拉取未读文章，自动生成摘要并按时间排序，支持标记已读和过滤关键词。
