# baidu-search

## 问题背景

海外搜索 API（如 Tavily、Brave Search）在国内访问不稳定，延迟高或直接不可用。baidu-search 基于百度搜索能力提供可靠的国产替代方案。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/baidu-search
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

执行搜索查询，返回结构化结果：

- **标题**：搜索结果的页面标题
- **URL**：对应网页地址
- **摘要**：页面内容摘要片段

## 使用方式

直接发送搜索关键词或问题：

```
搜索"Python 异步编程最佳实践"
查询"2026年两会主要内容"
```

## 适用场景

- 技术文档与 API 参考查询
- 事实性问题快速求证
- 中文内容搜索（中文结果质量优于国际引擎）
- 国内网络环境下的日常搜索需求

## 注意事项

- 依赖百度搜索 API，需确保网络可访问百度
- 搜索结果以中文内容为主，英文内容覆盖有限
