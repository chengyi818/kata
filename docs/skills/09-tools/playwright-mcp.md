# playwright-mcp

## 问题背景

AI Agent 需要可靠的浏览器自动化能力来处理 SPA、动态加载和反爬场景，但内置浏览器工具功能有限。该技能通过 MCP 协议调用 Playwright，提供完整的浏览器控制能力。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/playwright-mcp
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

### 页面导航

打开 URL、前进后退、刷新页面，支持设置超时和等待页面加载完成。

### 元素交互

点击按钮、填写表单、选择下拉框、上传文件，支持 CSS 选择器和文本定位。

### 截屏与截图

对整个页面或指定元素截图，支持全页截图和可视区域截图，输出 PNG 格式。

### 等待与同步

等待元素出现、网络请求完成或指定时间，确保 SPA 页面状态稳定后再操作。
