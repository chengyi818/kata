## 六、自定义 Skill 快速参考

```
~/.config/opencode/skills/
├── brainstorming/          (Superpowers)
├── systematic-debugging/   (Superpowers)
├── writing-plans/          (Superpowers)
└── kernel-debug/           (自定义)
```

```markdown
---
name: skill-name
description: Use when [触发条件] - [功能描述]
---

[工作流内容]
```
