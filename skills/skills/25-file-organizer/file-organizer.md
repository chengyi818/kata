# file-organizer

## 问题背景

下载文件夹和项目目录中文件混杂，手动分类耗时且容易遗漏。该技能自动识别文件类型并按规则整理，保持目录结构清晰。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/file-organizer
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

### 按类型分类

根据文件扩展名自动将文件归类到对应文件夹（如图片、文档、压缩包），支持自定义分类规则。

### 按日期分类

根据文件创建或修改时间，将文件归档到年/月文件夹结构中，便于时间线查找。

### 按项目分类

根据文件内容或路径特征，将文件分配到对应项目文件夹，适用于多项目工作环境。

### 批量重命名

按规则批量修改文件名，支持添加前缀/后缀、序列编号、正则替换等模式。

### 清理重复文件

扫描目录中的重复文件（基于内容哈希），列出重复项并支持保留最新版本或手动选择。
