# ralph-loop

> **编号**: 14
> **梯队**: 第三梯队
> **来源**: 社区

## 解决的问题

Agent 处理复杂任务时容易在中间步骤卡住并放弃。ralph-loop 提供强制完成机制。

## 适用场景

强制完成复杂任务，避免半途而废

**嵌入式场景**: 复杂驱动开发、多步骤内核配置任务。

## 安装方法

社区安装

## 使用方法

当 Agent 遇到复杂任务容易中途放弃时，ralph-loop 强制其循环执行直到完成。设置最大迭代次数和退出条件。

## 嵌入式开发场景

复杂驱动开发、多步骤内核配置任务。
