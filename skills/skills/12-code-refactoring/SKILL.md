# code-refactoring

> **编号**: 10
> **梯队**: 第二梯队
> **来源**: skills.sh

## 解决的问题

驱动代码需要适配新内核 API、迁移到新子系统时，重构风险高。结构化方法降低风险。

## 适用场景

驱动重构、代码结构调整

**嵌入式场景**: 驱动适配新内核版本、代码模块化重构。

## 安装方法

npx skills add supercent-io/skills-template --skill code-refactoring -g -y

## 使用方法

制定重构计划：识别坏味道、设计目标架构、分步实施、每步验证。确保重构不改变外部行为。

## 嵌入式开发场景

驱动适配新内核版本、代码模块化重构。
