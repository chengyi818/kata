# skill-creator

> **编号**: 19
> **梯队**: 第四梯队
> **来源**: skills.sh (115.6K 安装)

## 解决的问题

调试工作流、编译流程等重复操作每次都要重新描述。skill-creator 将其固化为可复用 Skill。115.6K 安装量。

## 适用场景

沉淀内核调试工作流

**嵌入式场景**: 将内核调试、交叉编译、驱动加载等工作流沉淀为自定义 Skill。

## 安装方法

Anthropic 官方: npx skills add anthropics/skills@skill-creator -g -y

## 使用方法

将重复性工作流打包为可复用 Skill：定义触发条件、输入输出、执行步骤。创建后安装到 ~/.config/opencode/skills/。

## 嵌入式开发场景

将内核调试、交叉编译、驱动加载等工作流沉淀为自定义 Skill。
