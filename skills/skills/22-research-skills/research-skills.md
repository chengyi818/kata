# research-skills

## 问题背景

多源研究（论文、技术文档、网页）需要频繁切换工具，手动整理和对比信息效率极低。该技能将研究流程集成到终端中，支持从问题定义到报告生成的完整闭环。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/research-skills
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

### 定义研究问题

明确研究范围和关键词，建立结构化的研究框架，避免信息搜集时偏离主题。

### 多源搜索

同时检索学术论文、技术文档和网页内容，自动去重并按相关性排序。

### 信息提取与对比

从搜索结果中提取关键信息，生成对比表格，帮助快速识别不同来源的异同点。

### 生成研究报告

将研究成果整合为结构化报告，包含引用来源、关键发现和结论，支持 Markdown 输出。
