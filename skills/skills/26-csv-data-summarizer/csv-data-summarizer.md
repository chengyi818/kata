# csv-data-summarizer

## 问题背景

大型 CSV 数据集手动分析效率低，难以快速了解数据分布和异常情况。该技能提供一键式数据概览，帮助快速掌握数据全貌。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/csv-data-summarizer
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

### 读取 CSV 文件

加载本地 CSV 文件，自动检测编码和分隔符，支持指定列名和跳过表头等选项。

### 生成数据摘要

输出行数、列名、每列数据类型、缺失值数量和唯一值统计，提供数据集的完整概览。

### 统计信息

对数值列计算均值、中位数、标准差、最小/最大值；对文本列统计长度分布和频率最高的值。

### 提取关键洞察

自动识别数据异常（空值过多、类型不一致、离群值），生成可操作的建议报告。
