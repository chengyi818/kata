# markitdown

> **编号**: 16
> **梯队**: 第三梯队
> **来源**: pip

## 解决的问题

芯片 datasheet 常为 PDF；厂商文档可能是 Word/PPT。转换为 Markdown 后 Agent 可直接阅读分析。

## 适用场景

PDF/PPT/Word/Excel/HTML → Markdown 转换

**嵌入式场景**: 芯片 datasheet PDF 转 Markdown、厂商文档格式转换。

## 安装方法

pip install markitdown[all]

## 使用方法

将各种格式文档转换为 Markdown：markitdown input.pdf > output.md。支持 PDF、PPTX、DOCX、XLSX、HTML 等格式。

## 嵌入式开发场景

芯片 datasheet PDF 转 Markdown、厂商文档格式转换。
