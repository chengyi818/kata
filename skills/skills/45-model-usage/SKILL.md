# model-usage

> **编号**: 43
> **梯队**: 低优先级-开发工具
> **来源**: ClawHub

## 解决的问题

多模型调用时不清楚各模型的成本占比。model-usage 提供用量透明化。

## 适用场景

模型用量/成本统计

**嵌入式场景**: API 调用成本监控、模型选择优化。

## 安装方法

ClawHub 安装

## 使用方法

统计各模型的 token 用量、成本、响应时间。生成用量报告和成本分析。

## 嵌入式开发场景

API 调用成本监控、模型选择优化。
