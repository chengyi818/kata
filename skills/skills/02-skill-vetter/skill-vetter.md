# Skill Vetter

## 背景

ClawHub 上约 20% 的 Skill 包含恶意代码，常见风险包括：读取 API 密钥、访问本地敏感文件、未授权向外部服务器传输数据。安装前无法判断 Skill 是否安全，用户需要在信任与功能之间盲目取舍。

Skill Vetter 在安装前对 Skill 进行全面安全审计，帮助用户在安装前识别潜在威胁。

## 安装

```bash
mkdir -p ~/.config/opencode/skills/skill-vetter
# 需手动创建 SKILL.md 文件，内容参考下方"使用方式"章节
```

## 命令说明

### `skill-vetter scan`

扫描目标 Skill 源码，检测 20+ 种危险信号，覆盖以下类别：

- **凭据访问**：检测是否读取环境变量中的密钥、token 或密码
- **代码混淆**：识别编码字符串、动态执行、eval 调用等隐藏意图的手法
- **未授权网络请求**：发现向未知域名发送数据或建立持久连接的行为

输出扫描报告，标注每项发现的风险等级（低/中/高/严重）。

### `skill-vetter audit`

执行四步完整审计流程：

1. **源码检查**：检查文件结构是否与声明的功能匹配，识别可疑的额外文件
2. **代码审查**：逐行分析关键代码段，标记异常逻辑和潜在后门
3. **权限评估**：评估 Skill 请求的系统权限是否超出其功能所需
4. **网络行为分析**：监控安装和运行时的网络活动，验证通信目标合法性

审计完成后生成综合安全评分和可读报告。

### `skill-vetter approve <skill-name>`

将已通过审计的 Skill 加入本地白名单，后续安装不再重复审查。

### `skill-vetter check-update`

检查 Skill Vetter 自身的威胁数据库是否为最新版本，确保能识别最新的攻击模式。
