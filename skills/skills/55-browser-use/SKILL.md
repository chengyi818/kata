## 解决的问题

需要浏览器交互的任务（如登录、填表）无法通过简单 HTTP 请求完成。58.4K 安装量。

## 适用场景

**嵌入式场景**: 芯片厂商网站登录、驱动下载页面操作。

ClawHub: npx skills add browser-use/browser-use -g -y
