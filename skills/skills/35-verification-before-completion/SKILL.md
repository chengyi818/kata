# verification-before-completion

> **编号**: 33
> **梯队**: Superpowers 内置
> **来源**: Superpowers (28.7K 安装)

## 解决的问题

Agent 容易在未验证的情况下声称完成。verification-before-completion 强制先验证再声明。28.7K 安装量。

## 适用场景

完成前验证

**嵌入式场景**: 编译验证、驱动加载测试、功能测试通过后再声明完成。

## 安装方法

已内置 (Superpowers)，无需安装

## 使用方法

在声称工作完成、修复、通过之前，必须运行验证命令并确认输出。证据先于断言。

## 嵌入式开发场景

编译验证、驱动加载测试、功能测试通过后再声明完成。
