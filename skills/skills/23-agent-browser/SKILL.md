# agent-browser

> **编号**: 21
> **梯队**: 第四梯队
> **来源**: skills.sh (140.4K 安装)

## 解决的问题

芯片厂商文档、驱动下载页面通常需要浏览器交互。Agent 无法直接 web_fetch JS 渲染页面。

## 适用场景

访问厂商文档、下载驱动

**嵌入式场景**: 访问芯片厂商文档网站、下载 BSP/驱动、抓取硬件规格。

## 安装方法

ClawHub: npx skills add vercel-labs/agent-browser -g -y

## 使用方法

Rust 无头浏览器自动化：导航到网页、点击、输入、截图、提取数据。支持 JS 渲染页面。140.4K 安装量。

## 嵌入式开发场景

访问芯片厂商文档网站、下载 BSP/驱动、抓取硬件规格。
