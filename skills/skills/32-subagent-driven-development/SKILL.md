# subagent-driven-development

> **编号**: 30
> **梯队**: Superpowers 内置
> **来源**: Superpowers (30.6K 安装)

## 解决的问题

大任务单次执行质量不稳定。子 Agent 分工提高质量和效率。30.6K 安装量。

## 适用场景

子 Agent 驱动开发

**嵌入式场景**: 复杂驱动开发分解为多个子任务并行实现。

## 安装方法

已内置 (Superpowers)，无需安装

## 使用方法

将实现计划分解为独立任务，分派给子 Agent 执行。主 Agent 监控进度、合并结果。

## 嵌入式开发场景

复杂驱动开发分解为多个子任务并行实现。
