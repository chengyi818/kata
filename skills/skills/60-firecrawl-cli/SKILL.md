# firecrawl-cli

> **编号**: 58
> **梯队**: 低优先级-搜索
> **来源**: ClawHub/Firecrawl

## 解决的问题

Agent 内置 web_fetch 在 JS 重网页和反爬虫网站上失效。Firecrawl 专门处理这些场景。

## 适用场景

JS 重网页抓取/爬取/搜索，返回干净 Markdown

**嵌入式场景**: 芯片厂商 JS 重文档网站抓取。

## 安装方法

npx -y firecrawl-cli init --browser --all

## 使用方法

6 个命令：search/scrape/crawl/map/browser/credit-usage。处理 JS 重网页和反爬虫网站，返回干净 Markdown。

## 嵌入式开发场景

芯片厂商 JS 重文档网站抓取。
