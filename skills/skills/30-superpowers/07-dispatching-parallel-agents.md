# Dispatching Parallel Agents

## 作用

当有 2 个以上独立任务可以同时进行时，将它们分派给不同的 agent 并行执行。每个 agent 获得精确的任务指令，互不干扰。

## 适用条件

- 任务之间**没有共享状态**
- 任务之间**没有顺序依赖**
- 每个任务可以独立完成

## 使用方式

1. **识别独立任务** — 哪些任务可以并行？
2. **为每个 agent 编写精确指令** — 不传递会话历史，只给必要的上下文
3. **同时分派** — 一次发出所有 agent
4. **收集结果** — 等待所有 agent 完成
5. **整合结果** — 合并各 agent 的产出

## 适用场景

- 多个不相关的 bug 同时修复
- 多个文件的独立修改
- 不同模块的测试编写
- 多个代码审查并行进行

## 注意

- 每个 agent 的上下文是隔离的，不能互相引用
- 指令必须精确完整，agent �有你当前的对话上下文
