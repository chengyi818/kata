# Finishing a Development Branch

## 作用

开发工作完成、测试全部通过后，引导你选择正确的集成方式：合并、创建 PR、还是清理。

## 前置条件

**必须先通过 verification-before-completion**，确认所有测试通过。

## 流程

1. **验证测试通过** — 运行所有测试确认通过
2. **展示选项**:
   - **合并** — 直接合并到主分支
   - **创建 PR** — 提交 Pull Request 供审查
   - **清理** — 清理分支、删除临时文件
3. **执行选择** — 按用户选择执行
4. **清理** — 删除工作分支、清理临时文件

## 适用场景

- 功能开发完成，准备合并
- Bug 修复完成，需要提交
- 实验性分支需要清理

## 嵌入式场景

- 内核补丁提交前的分支整理
- 驱动开发完成后的合并流程
- 多版本并行开发后的分支清理
