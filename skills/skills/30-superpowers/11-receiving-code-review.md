# Receiving Code Review

## 作用

收到代码审查反馈时，用严谨的态度处理：先理解、再验证、后回应。禁止表演式同意（"你说得对！"），每条反馈都要独立验证。

## 流程

1. **完整阅读** — 看完所有反馈再回应
2. **复述确认** — 用自己的话复述，确认理解无误
3. **对照代码验证** — 反馈是否真的对应当前代码？
4. **评估技术合理性** — 这个建议在技术上对不对？
5. **回应**:
   - 理解正确且合理 → 承认并实施
   - 理解有误 → 澄清
   - 技术上不合理 → 有理有据地反驳

## 禁止的行为

- ❌ "你说得完全对！"（没有验证就同意）
- ❌ 盲目实施所有建议
- ❌ 一次性修改所有反馈项

## 关键原则

- 一次处理一条反馈
- 每条都要测试验证
- 理性反驳是正当的，不是不礼貌
