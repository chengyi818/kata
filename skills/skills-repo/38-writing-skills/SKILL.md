# writing-skills

> **编号**: 36
> **梯队**: Superpowers 内置
> **来源**: Superpowers (27.8K 安装)

## 解决的问题

手动创建 Skill 容易格式错误、触发条件不当。writing-skills 提供标准化流程。27.8K 安装量。

## 适用场景

自定义 Skill 打包

**嵌入式场景**: 将内核调试工作流、交叉编译流程打包为自定义 Skill。

## 安装方法

已内置 (Superpowers)，无需安装

## 使用方法

创建新 Skill、编辑现有 Skill、或部署前验证 Skill 是否工作。将工作流固化为可复用 Skill。

## 嵌入式开发场景

将内核调试工作流、交叉编译流程打包为自定义 Skill。
