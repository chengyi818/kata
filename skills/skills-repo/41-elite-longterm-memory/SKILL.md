# elite-longterm-memory

> **编号**: 39
> **梯队**: 低优先级-开发工具
> **来源**: ClawHub

## 解决的问题

Agent 默认无跨会话记忆。elite-longterm-memory 提供持久化、可搜索的记忆系统。

## 适用场景

长期记忆系统 (WAL + vector search + git-notes)

**嵌入式场景**: 长期积累的设备兼容性数据、调试经验库。

## 安装方法

ClawHub 安装

## 使用方法

结合 WAL（预写日志）、向量搜索、git-notes 实现跨会话长期记忆。支持语义检索和历史回溯。

## 嵌入式开发场景

长期积累的设备兼容性数据、调试经验库。
