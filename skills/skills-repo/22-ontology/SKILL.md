# ontology

> **梯队**: 第四梯队

## 解决的问题

纯文本记忆缺乏结构化关联。Ontology 构建知识图谱，支持关系查询。27.6K 下载量。

## 适用场景

结构化记忆知识图谱

**嵌入式场景**: 记录芯片-驱动-项目之间的关系、硬件平台兼容性知识图谱。

## 安装方法

ClawHub: npx skills add oswalpalash/ontology -g -y

## 使用方法

构建类型化知识图谱，存储实体间的结构化关系。如'这个联系人在这家公司工作，该公司是这个项目的客户'。Agent 可遍历关系回答问题。

## 嵌入式开发场景

记录芯片-驱动-项目之间的关系、硬件平台兼容性知识图谱。
