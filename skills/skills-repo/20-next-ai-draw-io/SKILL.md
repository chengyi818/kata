# next-ai-draw-io

> **编号**: 18
> **梯队**: 第三梯队
> **来源**: MCP Server

## 解决的问题

手动绘制架构图耗时；AI 生成可快速迭代。适合驱动架构图、系统框图、状态机图。

## 适用场景

AI 驱动架构图/流程图生成

**嵌入式场景**: 驱动架构图、设备树拓扑、系统框图生成。

## 安装方法

MCP Server 安装

## 使用方法

用自然语言描述架构图/流程图，AI 自动生成 draw.io 格式的 XML 文件。支持系统架构图、数据流图、状态机等。

## 嵌入式开发场景

驱动架构图、设备树拓扑、系统框图生成。
