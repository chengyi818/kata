# 创建AI辅助编程能力考察试题

设计AI辅助编程能力考察试题（现场面对面机考），使用**1+N结构**（基础任务+独立可选扩展），要求白盒输出件。

## 出题要求

1. **时间控制**：AI半小时可完成基础任务（作为基础分），通常时间只够完成1~3个类
2. **1+N结构**：1个基础任务+N个独立可选扩展（考官灵活组合）
3. **白盒输出件**：需求澄清、设计文档、测试用例、commit记录（渐进给分）
4. **预装环境**：不引入网络下载依赖（时间可控）

## 考察点设置

1. **软实力优先**：AI交互、做事习惯、问题拆解确认、设计要求、调试定位（不考硬技能）
2. **避免AI完美题**：纯算法题避免，设计题推荐（多种方案各有优劣，考生评价AI设计）
3. **不强求高级概念**：SDD/TDD作为加分项
4. **需求细节故意模糊**：等考生澄清，考官临场微调

## 实现步骤

### 1. 设计基础任务

- 核心功能、状态管理、基础操作
- AI半小时可完成
- 自洽无依赖，有设计空间
- 语言无关，至少支持C++/Python/Java实现，描述中不出现与语言绑定的内容
- 随代码交付设计文档和测试用例，测试行覆盖率>=60%

### 2. 设计扩展任务

- 独立可选，可组合
- 设计模式或实现方式（符合开闭原则）
- 不写机制细节，让考生推导；不要给过多提示，保持开放性和难度
- 要求对每个扩展任务编写单独的增量设计文档并增量提交，测试要求同基础任务

常见类型：
- 功能系统：策略/工厂 | 字典映射/枚举+方法
- 增强系统：装饰器/组合 | 属性叠加/Builder
- 效果系统：观察者/状态 | 定时器/字典+时间戳
- 控制系统：责任链/状态 | 状态列表/位掩码

### 3. 设计考官指南

必须包含：
- 评分细则（基础60分+扩展分每项20~30不等）：
  1. 必须包含对AI的“验收标准澄清”和“上下文工程”相关的考察，且得分占比>=50%（重点考察）
  2. 得分点应该是给人的而不是给AI的，不要在仅取决于AI能力的因素上给分（注意：考生不需要编写任何代码，考核重心应在交互、设计决策和验收审核上）
  3. 过程大于结果：不能接受功能正确但设计糟糕的实现，评分点同时往设计质量上倾斜
- 追问示例：需求澄清/可扩展性/设计评价
- 观察要点：是否探索代码库、对齐设计、验证UT
- 环境预装要求：必须的编译器、测试框架、覆盖率报告工具等

注意：考官都是经验丰富的开发者，考官指南务必简明扼要，只包含必要的提示。不要包含记录表等花哨的内容，文档都是电子方式传递。

### 4. 询问迭代

与用户反复交流推敲完善考题细节，并给出自己模拟做题的思路辅助用户分析，在用户明确同意后才允许后续步骤。

### 5. 编写考题文档

考题和考官指南作为2个part写入同一个markdown文件，考试时只会把考题部分的基础内容发给学生，后续随机追加1~N个扩展点部分。

必须确保考题部分不会泄露评判标准，并且各扩展点自洽无依赖。

### 6. 创建代码框架

三语言必备：C++（google test）/ Python（unittest）/ Java（JUnit）

每套包含：类型定义、骨架类（仅示例1个方法）、demo文件、UT框架（包含1个空用例）、本地依赖

验证：运行编译和测试确保通过

注意：不要提供任何说明文件，注释里不要包含与解题相关的任何提示，让考生自己驱动AI探索

### 7. 自洽性检查

基础任务自洽、扩展独立无冲突、框架匹配考题、测试通过

## 常见错误

| 错误 | 修复 |
|------|------|
| 基础任务AI半小时无法完成 | 简化基础任务 |
| 扩展重叠/冲突 | 设计独立扩展，验证组合 |
| 纯算法题 | 改为设计题（多方案各有优劣） |
| 写机制细节 | 删除，让考生推导 |
| 无白盒输出件 | 必须设置需求澄清/设计文档等 |
| 引入网络下载 | 最小化依赖/本地打包 |
| 框架测试失败 | 运行测试确保通过 |
| 需求完全明确 | 故意模糊细节，等考生澄清 |

## 评分模板

```
基础部分（60分）：AI交互能力
- 探索代码库、对齐设计、验证证据、审核输出

扩展任务X（Y分）：
- 设计模式/实现方式选择（符合开闭原则）A分
- 功能正确实现 B分
- 增量文档/测试/commit C分

加分项：SDD/TDD 0~10分
```

## 考官追问

- 需求澄清："XXX未明确，如果YYY？"
- 可扩展性："如何新增ZZZ？"
- 设计评价："AI方案A/B优劣？"
- AI交互："如何验证AI实现？（UT证据而非信任）"

## 考试流程

仅给基础任务 → 完成后渐进给扩展 → 观察AI交互 → 追问测试 → 按细则评分
