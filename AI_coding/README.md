# AI辅助编程机试题

基于日常常见的生活场景, 设计一道AI辅助编程招聘机试题，面向初级工程师，重点考察需求澄清，设计模式与SOLID原则。
设计多个方便考察设计模式的场景，供我选择

**统一约束**：
1. 预计耗时30分钟（基础15min + 扩展15min），默认python语言，不限其他语言(c,cpp,java等)，允许使用AI编程工具。
2. 需要有反AI设计
3. 不需要输出cpp/java/python的代码，输出件为基础任务和扩展点的题目描述

---

## 设计模式 
1. 策略模式 (Strategy) 
2. 工厂模式 (Factory) 
3. 模板方法 (Template Method) 
4. 装饰器模式 (Decorator) 
5. 责任链模式 (Chain of Resp.)
6. 其他常见的设计模式

### SOLID原则覆盖
1. SRP 单一职责 
2. OCP 开闭原则 
3. LSP 里氏替换 
4. ISP 接口隔离 
5. DIP 依赖反转
